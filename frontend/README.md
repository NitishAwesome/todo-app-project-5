# React + Vite + TypeScript

This template provides a minimal setup to get React working in Vite with HMR.

## Project Structure
- `src/components/Layout.tsx`: Shared layout with responsive Navbar and Sidebar (Sanskruti)
- `src/components/TaskWorkspace.tsx`: Main task workspace with filter tabs, search, and sorting (Ishwari)
- `src/components/TaskFormModal.tsx`: Add & Edit task modal with form validation (Sanyukta)
- `src/taskAPI.ts`: Backend task API client
